! Feature Focus: Edge Routing & Static Route Redundancy

hostname EDGE-R01

! 1. Interface IP Configurations
interface GigabitEthernet0/0/0

 no shutdown
 exit

interface GigabitEthernet0/0/1

ip route 10.53.0.0 255.255.0.0 10.53.100.2
ip route 10.53.0.0 255.255.0.0 10.53.100.6 10
